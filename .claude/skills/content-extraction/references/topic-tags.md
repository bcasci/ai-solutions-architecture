# Topic Tags

Assign one or more of these tags to each inventory record. Tags map content to site sections.

## Foundations

- `api-basics` — API setup, authentication, first calls
- `authentication` — API keys, auth patterns
- `models` — Model selection, capabilities, comparison
- `messages-api` — Messages API structure, parameters, usage
- `prompts` — Prompt design, formatting
- `system-prompts` — System prompt patterns, role setting
- `prompt-engineering` — Advanced prompt techniques
- `streaming` — Streaming responses, SSE handling
- `tool-use` — Function calling, tool definitions
- `structured-output` — JSON mode, structured responses
- `vision` — Image input, multimodal

## Patterns

- `rag` — Retrieval-augmented generation
- `multi-turn` — Conversation management, context
- `context-management` — Context window strategies
- `classification` — Text classification, routing
- `extraction` — Data extraction, parsing
- `summarization` — Document summarization
- `code-generation` — Code writing, review, analysis
- `evaluation` — Output evaluation, testing
- `orchestration` — Multi-step workflows, chaining

## Agents

- `agents` — Agent concepts, architecture
- `agent-loops` — Agent execution loops
- `agent-sdk` — Anthropic Agent SDK
- `multi-agent` — Multi-agent systems
- `claude-code` — Claude Code platform, usage
- `claude-code-commands` — Custom slash commands and command patterns
- `hooks` — Claude Code hooks (PreToolUse, PostToolUse)
- `skills-authoring` — Creating, configuring, sharing, and troubleshooting skills
- `tool-design` — Designing tools for agents
- `parallelization` — Parallelization workflow patterns

## Features

- `extended-thinking` — Extended thinking / chain-of-thought budget
- `files-api` — Code execution sandbox and Files API
- `ci-cd` — GitHub Actions, automation pipelines

## Production

- `error-handling` — Error handling, retries, resilience
- `rate-limits` — Rate limiting, throttling
- `safety` — Content filtering, guardrails
- `cost` — Cost optimization, token management
- `monitoring` — Observability, logging, tracing

## Adding New Tags

If content doesn't fit an existing tag, propose a new one in the Notes field using the format: `category-name` with a brief description. New tags will be added to this file during inventory review.
