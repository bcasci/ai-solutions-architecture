## Project

Solutions Architecture — a static site about Anthropic solutions architecture, built with Astro + Tailwind CSS v4 + MDX.

## Commands

- `npm run dev` — start dev server at localhost:4321
- `npm run build` — build to `./dist/`
- `npm run preview` — preview production build

## Environment

- Node.js 22.16.0 (managed via `.tool-versions` / asdf)
- Astro 6.x with MDX integration
- Tailwind CSS v4 (via Vite plugin) + @tailwindcss/typography
