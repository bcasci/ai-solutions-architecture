A fully working terminal chatbot that maintains conversation history across turns and streams responses in real time. Copy, paste, run.

## The Script

```python
import anthropic

client = anthropic.Anthropic()
MODEL = "claude-sonnet-4-20250514"

SYSTEM_PROMPT = """You are a helpful assistant. Be concise and direct.
If you don't know something, say so. Don't make things up."""


def chat():
    messages = []
    print("Chat with Claude (type 'quit' or Ctrl+C to exit)\n")

    while True:
        try:
            user_input = input("You: ").strip()
        except (KeyboardInterrupt, EOFError):
            print("\nGoodbye!")
            break

        if user_input.lower() in ("quit", "exit", "q"):
            print("Goodbye!")
            break
        if not user_input:
            continue

        messages.append({"role": "user", "content": user_input})

        # Stream the response for real-time output
        print("Claude: ", end="", flush=True)
        assistant_text = ""

        with client.messages.stream(
            model=MODEL,
            max_tokens=1024,
            system=SYSTEM_PROMPT,
            messages=messages,
        ) as stream:
            for text in stream.text_stream:
                print(text, end="", flush=True)
                assistant_text += text

        print()  # newline after response
        messages.append({"role": "assistant", "content": assistant_text})

        # Trim history to avoid exceeding context limits
        if len(messages) > 40:
            messages = messages[-30:]


if __name__ == "__main__":
    chat()
```

## How It Works

1. **Message history** lives in a list that grows with each turn. Both user and assistant messages get appended, giving Claude full conversational context.
2. **Streaming** uses `client.messages.stream()` so text appears token-by-token in the terminal instead of waiting for the full response.
3. **History trimming** kicks in after 40 messages, keeping the last 30. This prevents context window overflow on long conversations.
4. **Clean exit** handles `Ctrl+C`, `EOF`, and text commands gracefully.

:::tip
For production chatbots, replace the naive trim with a smarter strategy: summarize old messages into a rolling context block, or use a database to store and retrieve relevant history. See [RAG](/agents/rag) for retrieval-based approaches.
:::

:::warning
The `messages` list is your token budget. Each turn adds to it. A 20-turn conversation can easily consume 10k+ tokens of context. Monitor usage with `response.usage.input_tokens` if cost matters.
:::
