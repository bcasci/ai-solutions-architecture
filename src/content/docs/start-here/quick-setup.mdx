Claude is a family of language models you interact with through several interfaces. Understanding which pieces exist — and when to reach for each — is the first step to building well.

## The Building Blocks

| Layer | What it is | When to use it |
| --- | --- | --- |
| **Messages API** | HTTP API for sending messages and getting responses | Every custom integration — it's the foundation |
| **Python / TypeScript SDKs** | Typed wrappers around the API | Any production app (handles auth, retries, types) |
| **Claude Code** | Terminal-based coding assistant with built-in tools | Developer workflows, code generation, automation |
| **MCP (Model Context Protocol)** | Standard for connecting Claude to external tools and data | Reusable tool servers, shared integrations, ecosystem |

These aren't competing options — they compose. A typical production system uses the **SDK** to call the **Messages API**, with **MCP servers** providing tool access, and developers using **Claude Code** to build and iterate.

## The Messages API

Every interaction with Claude goes through the [Messages API](/the-api/messages-api). You send a list of messages, Claude returns a response. The SDKs wrap this API — they don't replace it.

```python
from anthropic import Anthropic

client = Anthropic()  # reads ANTHROPIC_API_KEY from environment

message = client.messages.create(
    model="claude-sonnet-4-20250514",
    max_tokens=256,
    messages=[
        {"role": "user", "content": "Explain API rate limiting in one sentence."}
    ]
)

print(message.content[0].text)
```

```typescript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic(); // reads ANTHROPIC_API_KEY from environment

const message = await client.messages.create({
    model: "claude-sonnet-4-20250514",
    max_tokens: 256,
    messages: [
        { role: "user", content: "Explain API rate limiting in one sentence." }
    ],
});

console.log(message.content[0].text);
```

From this foundation, you add capabilities:

- **[System prompts](/prompting/system-prompts)** shape Claude's behavior and persona
- **[Tool use](/the-api/tool-use)** lets Claude call functions in your code
- **[Streaming](/the-api/streaming)** delivers responses token-by-token
- **[Extended thinking](/prompting/extended-thinking)** gives Claude a reasoning scratchpad for complex problems
- **[Structured output](/prompting/structured-output)** forces responses into JSON or other formats

## Tool Use — The Key Capability

A key API feature is [tool use](/the-api/tool-use). You define functions Claude can call — database queries, API requests, calculations — and Claude decides when and how to use them. This is what makes Claude an active participant in your system rather than just a text generator.

Tool use shows up everywhere:
- **[Agents](/agents/agent-architecture)** use tools to take actions in autonomous loops
- **[MCP](/mcp/mcp)** standardizes how tools are defined, discovered, and shared
- **[Claude Code](/claude-code/basics)** ships with built-in tools (Read, Edit, Bash, etc.) and connects to MCP servers for more

## Claude Code

[Claude Code](/claude-code/basics) is a terminal-based assistant that uses Claude with a fixed set of developer tools. It's not a separate API — it's an application built on the same Messages API and tool use protocol.

What makes it relevant to this guide: Claude Code is extensible via [hooks](/claude-code/hooks) (shell commands triggered by events), [skills](/claude-code/skills) (reusable prompt templates), and [MCP servers](/mcp/client-integration#claude-code-as-mcp-client) (custom tools you connect).

## MCP

[MCP (Model Context Protocol)](/mcp/mcp) standardizes how Claude connects to external tools and data. Instead of defining tool schemas inline in your API calls, you run MCP servers that expose tools through a common protocol.

MCP matters when you have tools that are shared across projects, used by multiple team members, or available from the [pre-built ecosystem](/mcp/client-integration#pre-built-servers) (GitHub, PostgreSQL, Slack, etc.).

## Getting Set Up

To follow the examples in this guide:

1. **Get an API key** at [console.anthropic.com](https://console.anthropic.com/) → API Keys
2. **Set it in your environment:**
   ```bash
   export ANTHROPIC_API_KEY="sk-ant-..."
   ```
3. **Install the SDK:**
   ```bash
   # Python
   pip install anthropic

   # TypeScript
   npm install @anthropic-ai/sdk
   ```

<Callout type="tip">
The SDKs read `ANTHROPIC_API_KEY` from the environment automatically. You never need to pass it in code.
</Callout>
